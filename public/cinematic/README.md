# Cinematic K

`k-obsidian.png` is custom transparent artwork generated with the built-in image-generation tool for this website. It is used as a responsive hero and as the reduced-motion/WebGL fallback. The focus scene has a separate procedural Three.js K.

Prompt: Create an isolated, immediately readable capital K with an upright stem and two diagonal arms. Use thick extruded fractured black obsidian/dark titanium, sharp bevels, molten-orange fissures, silver directional light on upper-left facets, and cinematic photorealistic texture. Almost front-on, slight three-quarter angle, transparent background, no rings, no floor, no UI or captions.
